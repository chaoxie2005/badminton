### web 版（主线，Next.js + Supabase）发现的问题
1. **轮询竞态** `lib/use-board-poll.ts`：只比较 `updatedAt !==`，慢/乱序的旧响应会把乐观更新的比分回退；`pause()` 挡不住在途请求。修复方向：比较时间戳单调性或请求序号。
2. **设置表单被重置** `components/board-controller.tsx`（~208 行）：同步 meta 的 effect 依赖 `agreementsLocked`，第一分产生即全量 `setMeta`，覆盖用户未保存输入。
3. **论坛附件孤儿文件** `lib/forum.ts`（~304/390 行）：收集附件引用失败被 catch 吞掉仍继续删 DB，存储对象泄漏。
4. **vision 半失败不一致** `lib/vision.ts` + `drivers/supabase-vision.ts`：clip 行 insert 成功但 status 更新失败时，文件被删、DB 行残留（列表可见但播放 404）。
5. **大屏定时器未清理** `components/big-screen.tsx`（343/396 行）：两处 `setTimeout` 无 cleanup，重复触发会叠加。
6. 次要：`lib/play-calendar.ts:44` 用 UTC"明天"做上限，负时区用户可记未来 2 天内日期；`lib/use-voice-announcement.ts:70` 未等 `voiceschanged` 事件，Chrome 首次 getVoices() 为空导致中文语音失效。
7. 小瑕疵：`lib/boards.ts` `undoLastEvent` 未检查 `archivedAt`。

### 小程序版（旧原型）发现的问题
- **cloudfunctions/scoreboard/index.js 所有 action 均无归属校验**：update/remove/updateScore/finish 等只凭 id 操作，云函数有管理员权限，知道 id 即可改/删他人记分牌（安全漏洞，原型阶段影响有限）。
- `toggleCard` 注释说"再次点击取消"，实现只会 +1，无法取消。
- `updateScore` 信任客户端传的 newScore/previousScore，无校验。
