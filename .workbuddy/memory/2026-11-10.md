# 2026-11-10

## Web 论坛评论功能增强（`web/`）

范围仅 Web 端（Next.js App Router），小程序 `miniprogram/` + `cloudfunctions/` 的评论未改动。

### 数据层
- `lib/types.ts`：`CommentSnapshot` 新增 `replyToId` / `replyToAuthorName` / `editedAt`；新增 `CommentSort`（`oldest|newest|hot`）与举报相关类型、`COMMENT_REPORT_REASONS` / `COMMENT_REPORT_LABELS` / `COMMENT_REPORT_STATUS_LABELS`。
- `lib/dev-store.ts`（node:sqlite 本地驱动）：comments 表加 `reply_to_id`、`reply_to_author_name`、`edited_at`；新增 `comment_reports` 表（刻意不加 comments 外键，评论删除后仍保留处理记录）+ `comment_reports_status_idx`；新增 `devToggleCommentLike` / `devCreateCommentReport`（`ON CONFLICT DO NOTHING`，与云端语义对齐）/ `devListCommentReports` / `devHandleCommentReport`。
- `lib/drivers/supabase.ts`：同名同签名实现，点赞走 `rpc("toggle_comment_like")`，举报用 `upsert(..., ignoreDuplicates: true)`，列表批量补评论作者/内容 + `commentExists`。
- `supabase/schema.sql`：新增「评论增强」增量段（三列 + `comments_thread_hot_idx` + `toggle_comment_like` SECURITY DEFINER + `comment_reports` 表，仅 service_role 全权）。

### 业务层
- `lib/forum.ts`：`listCommentsPage(..., sort)` 透传排序；新增 `toggleCommentLike`（先校验评论归属帖子）、`normalizeReportInput`、`createCommentReport`、`listCommentReports`、`handleCommentReport`。
- `lib/forum-moderation.ts`（新）：`assertCleanContent`（内置广告词 + `FORUM_BLOCKED_WORDS`，去空白/标点归一化防「刷 单 兼 职」绕过）、`assertCommentRate`（内存滑动窗口，默认 10s / 8 条）。

### API
- `comments/route.ts`：GET 解析 `sort`；POST 前置限流。
- 新增 `comments/[commentId]/like/route.ts`、`comments/[commentId]/report/route.ts`、`admin/comment-reports/route.ts`、`admin/comment-reports/[id]/route.ts`。

### 前端
- 新组件 `comment-like-button.tsx`（乐观更新 + `useEffect` 同步服务端状态）、`comment-item.tsx`（楼层号 / 楼主徽章 / 已编辑 / 回复 @跳转 / 长文折叠 / 举报表单 / Ctrl·⌘+Enter 保存）、`admin-comment-reports.tsx`（筛选 + 待处理徽章 + 标记已处理/忽略/删除评论并处理）。
- `comment-section.tsx` 重写：排序 tab（URL 带 `#comments`）、子楼折叠（预览 3 条）、楼层号仅在 `oldest` 计算、发布后跳页逻辑区分回复/非默认排序、回复条显示被回复者与原文前 30 字。
- `forum/[id]/page.tsx`：解析 sort、`Pagination` 用 `pageQuery` 保留排序参数。

### 踩坑记录
- 本地 `dev-store` 重复举报原为 `DO UPDATE`，与 Supabase `ignoreDuplicates` 不一致，回归测试 `'abuse' !== 'spam'` 失败 → 改为 `DO NOTHING` 统一。
- `npm run build` 覆盖 `.next` 会让正在跑的 `next start` 返回 502，需先杀端口再 `npm start`。
- 循环依赖：举报常量放 `lib/types.ts`，不要放 `forum-moderation.ts`。
