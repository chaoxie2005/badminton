# 2026-11-07

## Web 版 UI / 交互美化（用户要求"帮我美化一下UI交互和界面"）

前提：项目已有成熟设计系统（`app/globals.css` 里 @theme + 4 套主题 dark/light/sand(wimbledon)/cyber(glacier)、view transitions、reduced-motion、导航进度条、主题切换器），因此采取**精修而非重做**。

改动文件：
- `app/globals.css`
  - body 加双色极淡径向光晕（跟随主题色），移动端 `background-attachment: scroll` 降级
  - 细窄主题色滚动条（Firefox `scrollbar-*` + WebKit 伪元素）
  - `.panel` 过渡；`a.panel:hover`/`button.panel:hover` 在 `(hover:hover) and (pointer:fine)` 下微浮 3px + 主题色描边/阴影；`:active` 按压缩放优先
  - `.btn-primary` 加 `position/isolation/overflow` + `::after` 斜向高光掠过（不改底色，避免浅色主题白字对比度问题）；hover 阴影增强；`.btn` hover 上浮 1px
  - `.field` hover 边框、focus 光环；`.chip` 过渡
  - 新增 `.stagger` 交错入场（**关键：用 `animation-fill-mode: backwards` 而非 `both`，否则残留 transform 会盖掉 hover 位移**）、`.hero-accent` 柔光（只加 text-shadow 不改文字色，保证对比度）、`.hero-preview-glow`（需 `isolation: isolate` 才能让 z-index:-1 伪元素可见）、`.surface-glow`、`.bottom-nav-active` 小灯点
  - 所有新增动效在 `prefers-reduced-motion: reduce` 下禁用
- `app/page.tsx`：hero 强调字加柔光、预览加场灯光晕、两个卡片 grid 加 `stagger`、CTA 加 `surface-glow`
- `app/boards/page.tsx`、`app/forum/page.tsx`：列表容器加 `stagger`
- `components/site-chrome.tsx`：顶栏与移动端底栏改 `bg-ink/90 + backdrop-blur-xl`；当前页图标 span 加 `bottom-nav-active`

验证：`tsc --noEmit` 0 错误；回归测试 71/71 通过（新增 class 不破坏测试里的 className 包含断言）。

经验：这个项目测试用 `className.split(" ").includes(name)` 做结构断言，**只加 class、不删改原有 class** 是安全做法；CSS 层改动对测试零影响。`npm run build` 上次在本机卡在 static-generation（环境问题），dev 预览可用。
